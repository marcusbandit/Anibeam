Why Anibeam starts with no download sources

A download source is a search feed that Anibeam checks when you look for episodes on the Downloads page.

Anibeam is a local library and player, so it ships completely empty with no download sites built in, and this website does not list or recommend any sites. When you want to search for episodes inside Anibeam, you have two ways to plug sources in:

What a source list is (and where to find one)

Think of a source list as a shared address book for Anibeam. It is a single web link to a JSON file, such as https://example.com/anibeam/repo.json, that tells Anibeam which search sites are available and how to read their results.

  • Data only, never executable code: A source list does not install plugins or run scripts on your computer. It only lists web addresses and search formats that Anibeam already knows how to read.
  • Checked against tampering: Every list carries a digital signature from its author. Anibeam checks that signature when you add the list and remembers it, so nobody else can quietly swap out the list later.
  • Ready right away: As soon as you add a list, Anibeam automatically turns on every source in it that works without a login or API key. Sources that need your own account or key wait until you fill them in.
  • Easy updates: Whenever the list's maintainer fixes a broken site or updates an address, Anibeam offers the update inside Settings.
Where to find source lists: Discord (coming soon)

This website and Anibeam's GitHub repository do not host or link to download sites. Once the Anibeam Discord server opens (coming soon), it will have a community channel where users share source lists with one another.

Lists shared there come from community members rather than the Anibeam app itself. Because a source list decides which websites Anibeam sends your searches to, only add links from people or communities you trust.

How to add a source list

You can add a source list in any of three places: the Downloads step during first-time setup, the Downloads page before any source is added, or under Source lists at the top of SettingsDownloads.

  1. Copy the source list's web address (a link to a single file, such as https://example.com/anibeam/repo.json).
  2. Paste it into the box labeled Paste the address of a source list and click Add.
  3. Wait a second while Anibeam checks the list. You will see a green checkmark confirming how many sources were turned on (for example, Added Example: 5 sources are on). Those sources are ready to search immediately.
  4. Optional, for sources that need a key or login: If any source in the list requires an API key, password, or server address (such as a private tracker or your own Prowlarr or Jackett), Anibeam notes it underneath with a Fill in button. Click Fill in, click Install next to that source, enter the details it asks for, and click Install again.

Any API keys or logins you enter are stored in your computer's password keyring, never in your library database or backup exports.

Turning sources on and off

Every enabled source appears as a clickable chip under the search box on the Downloads page, so you can toggle individual sources on or off for any search. Lists you added before and removed show up under Used before for one-click re-adding.

Add your own source directly

You do not need a source list if you already have a site's RSS search link, a private tracker feed, or a Torznab feed from your own Prowlarr or Jackett setup. You can add any single source directly in SettingsDownloads under Add one by hand:

  1. Type a short, unique Name for the source (for example, Example).
  2. Paste the feed's search URL into the http://...{query}... box, replacing the search term with {query}.
  3. Click Add. The source shows up right away marked added by you and is ready to search.

How the URL should look

Start with a search RSS link from the site and swap the search word for {query}. Whenever you search in Anibeam, Anibeam replaces {query} with the anime title automatically.

# 1. What a normal RSS search link looks like in your browser:
https://example.com/rss?q=frieren

# 2. Replace the search term with {query} and paste this into Anibeam:
https://example.com/rss?q={query}

More examples of valid direct source addresses:

Type Example address to paste
Standard RSS search https://example.com/rss?q={query}
Category-filtered RSS https://example.com/?page=rss&c=anime&q={query}
Search term in path https://example.com/search/rss/{query}/
Torznab (Prowlarr / Jackett) https://example.com/torznab/api?t=search&apikey=YOUR_KEY&q={query}
A bare homepage will not work

Pasting a plain site address like https://example.com/ will be rejected. The link must start with http:// or https://, point to an RSS or Torznab feed (not a regular HTML webpage), and include {query} where the search text goes.

API keys and passwords stay safe: If your link includes a secret parameter such as apikey=, token=, or passkey= (or a user:password@ login), Anibeam automatically lifts that secret out of the URL and saves it in your system's password store instead of your library database.

What format Anibeam expects

When Anibeam fetches your URL, it expects standard RSS 2.0 XML or Torznab XML containing one <item> per release. Each item needs a <title> and a torrent or magnet download link (in <link>, <enclosure url="..."/>, or a Torznab magneturl attribute). Optional fields like file size and seeder counts are picked up automatically when present:

<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>
    <title>Example Anime Feed</title>
    <item>
      <title>[SubGroup] Example Show - 01 (1080p).mkv</title>
      <link>https://example.com/download/example-show-01.torrent</link>
      <!-- Magnet links (magnet:?xt=...) and <enclosure url="..."/> also work -->
      <size>1.4 GiB</size>
      <seeders>42</seeders>
    </item>
  </channel>
</rss>

Keep sources up to date

Anibeam checks your attached source lists each time the app starts. You can also check manually anytime in SettingsDownloads by clicking Refresh lists.

  • Updating a source: When a newer version is available, click the Update button next to that source (for example, Update to v2). If an update changes the web address that receives your API key, Anibeam pauses and asks you to confirm first.
  • Removed sources: If a list stops offering a source you installed earlier, it stays installed with a note saying it is no longer offered. Click Remove if you want to clean it up.
  • Signing key changed: If a list's maintainer switches to a new signing key, Anibeam refuses the update to protect you. If you know the change is legitimate, remove the list and add it again to accept the new key.

Want to verify a list matches what its maintainer published? Compare the Key fingerprint shown on its row in SettingsDownloads against the fingerprint the maintainer shared.

For maintainers: creating your own source list

Regular Anibeam users can skip this section. If you want to publish and host your own signed source list for yourself or a community, open the technical reference below.

Source list format, signing steps, and supported kinds

A source list is a single JSON file using format anibeam-endpoint-repo version 1. It wraps a base64-encoded index JSON in payload alongside an ed25519 signature over those exact bytes in signature. The decoded index contains the list's name, its public key, an increasing integer serial, and the full array of source definitions.

  1. Generate a private signing key once and keep it secret:
    $openssl genpkey -algorithm ed25519 -out list-key.pem
  2. Write one JSON definition per source with a permanent id, display name, integer version, kind, and a url template containing {query}.
  3. Validate and sign the index. You can copy the schema, validation script, and GitHub Actions signing workflow from marcusbandit/anibeam-endpoints-template.
  4. Host the signed repo.json file over HTTPS (such as https://example.com/anibeam/repo.json or a GitHub raw file URL) and share the URL alongside your key's fingerprint.

Example source definition:

{
  "id": "example-rss",
  "name": "Example",
  "version": 1,
  "lang": "en",
  "kind": "rss",
  "url": "https://example.com/rss?q={query}&key={api_key}",
  "auth": [
    { "key": "api_key", "label": "API key", "secret": true }
  ],
  "rate": { "per_minute": 30 }
}

Each source picks one built-in kind describing how Anibeam parses its response:

rss
Any standard RSS feed whose address accepts {query}.
filtered-rss
A base site address that Anibeam turns into a category-filtered RSS search.
json-feed
A JSON feed of torrent entries in a fixed layout.
json
A JSON search API paired with a field mapping for each result's title, hash or link, and size.
torznab
A Torznab search endpoint, such as a self-hosted Prowlarr or Jackett proxy.
  • Every auth key appears as a {key} placeholder in url, so secrets are filled at request time and never written to stored URLs or logs.
  • rate caps request frequency and can only slow Anibeam down.
  • Increase serial every time you publish (Anibeam rejects older serials), increase a source's version whenever you edit it, and keep the same signing key.
  • To test a list locally before publishing, paste a local file path to your repo.json straight into the source list box in Anibeam.
