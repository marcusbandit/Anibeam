Download and install

Grab Anibeam for your device from the download page. Desktop builds are available for Linux, Windows, and Apple silicon Macs, and there is a standalone phone app for Android and iPhone.

If you use Linux or macOS and prefer the terminal, this one-line installer picks the right package for your system automatically:

$curl -fsSL https://anibeam.app/install.sh | sh
macOS: opening Anibeam for the first time

Because Anibeam is a free open-source build that is not notarized with Apple, macOS will block the very first launch.

  1. Drag Anibeam into your Applications folder and try opening it once.
  2. Open macOS System SettingsPrivacy & Security, scroll down to the notice about Anibeam, and click Open Anyway.

If you prefer a terminal command instead:

$xattr -dr com.apple.quarantine /Applications/Anibeam.app
Windows: getting past the SmartScreen warning

The Windows installer installs for your user account without asking for admin rights, and is not code-signed. If Windows Defender SmartScreen shows a blue warning window, click More info and then Run anyway.

A portable .zip is also available on the download page if you would rather unzip and run Anibeam without installing it.

Linux: package managers and AppImage notes

The download page has ready-to-copy commands for Arch (AUR), Ubuntu and Debian (apt), and Fedora (dnf). Those installs update through your normal system updates.

If you downloaded the AppImage instead, mark it executable and launch it:

$chmod +x ./Anibeam-*.AppImage && ./Anibeam-*.AppImage

If your distro says FUSE is missing, install libfuse2 (or libfuse2t64 on Ubuntu 24.04+) or run the AppImage with --appimage-extract-and-run.

Looking to install on Android or iPhone? See the Phone app and streaming guide.

The first-time setup

The first time you open Anibeam, a short guided walkthrough helps you get set up in about a minute. Every step is optional and can be skipped or changed later.

  1. Pick your language: Anibeam starts in your system language and supports 13 languages. Switch it at the top of the Welcome screen if you want a different one, then click Get started.
  2. Choose your anime folder: Click Choose folder and select the parent folder that holds your anime shows (for example, Videos/Anime). Don't have any anime files yet? Click I don't have a folder yet and Anibeam creates an empty Anime folder for you. Your library scans in the background while you continue.
  3. Connect AniList or MyAnimeList (optional): Click Connect next to whichever site you use, approve Anibeam in your browser, and every episode you finish will update your online list automatically. See AniList and MyAnimeList for details.
  4. Set up downloads (optional): If you want to search for and download episodes inside Anibeam, paste a source list link under Download sources and click Add (not sure what that is? Read Download sources first). Below that, leave Let Anibeam handle it selected to use the built-in torrent client with zero setup, or pick I already use qBittorrent if you run your own.
  5. Set your Watch together name (optional): Type the display name friends will see when you watch episodes together in a synced room.
  6. Click Open Anibeam: You're ready to watch!
Tip

Every step has a Skip for now button at the bottom. You can start with just a local folder (or nothing at all) and connect trackers or download sources whenever you feel like it.

Find your way around Anibeam

Anibeam keeps navigation simple with four main pages in the sidebar and two utility buttons at the bottom.

Home

Your launchpad. Resume the show you were watching with one click, see episodes airing this week, check recently downloaded shows, and browse personalized recommendations.

Library

Every show in your folders as poster cards. Use the tabs across the top to filter by Series, Movies, or Watched, view your On my list shows, explore Stats, or open Fix matches.

Airing

Browse every anime airing this season (or jump to past and upcoming seasons), see what came out in the last 24 hours, add shows to your Planning list, or grab episodes directly.

Downloads

Search your download sources by show or release name, paste magnet links, subscribe to airing shows so new episodes arrive automatically, and free up space by clearing watched files.

  • Join room (bottom of the sidebar, or press Ctrl+J): Start a Watch together room or enter a friend's 6-letter room code.
  • Settings (gear icon at the bottom, or press Ctrl+,): Manage folders, accounts, themes, subtitles, keyboard shortcuts, downloads, and backups. Use the Search settings box at the top to jump straight to any option.
Good to know

Press ? anywhere in Anibeam (including inside the video player) to pop up a cheat sheet of every keyboard shortcut that works on the current screen.

Run the setup again

Want to go through the guided setup again later?

  1. Open SettingsAbout.
  2. Click Run setup again.

You can also change any individual setting directly in its own Settings tab without rerunning the walkthrough.
