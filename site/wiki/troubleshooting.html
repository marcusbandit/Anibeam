First step: check the Activity log

Whenever something fails or behaves strangely, Anibeam records the exact reason in the Activity log:

  1. Click the status bar along the very bottom of the Anibeam window (or press Ctrl+L) to open Activity.
  2. Switch the filter at the top to Problems to see only warnings and errors.
  3. Click any line to copy its message to your clipboard (helpful if you need to ask for help or file a bug report).

macOS, Windows, or Linux blocks Anibeam on first launch

macOS says Anibeam cannot be opened or is unverified
Official Mac builds are not notarized with Apple. Open macOS System SettingsPrivacy & Security, scroll to the Anibeam notice, and click Open Anyway (or run xattr -dr com.apple.quarantine /Applications/Anibeam.app in Terminal).
Windows Defender SmartScreen says "Windows protected your PC"
The Windows installer is unsigned. Click More info on the SmartScreen window, then click Run anyway.
Linux AppImage won't open or complains about FUSE
Make sure the file is executable (chmod +x ./Anibeam-*.AppImage). If FUSE is missing on your system, install libfuse2 (or libfuse2t64 on Ubuntu 24.04+) or launch the file with --appimage-extract-and-run.

My library stays empty

  • Wrong folder level picked: Make sure you added the parent folder holding your shows (such as Videos/Anime), not a single show's folder (Videos/Anime/Shell City). Check what is listed under SettingsLibrary.
  • Files sitting loose without show folders: Each series needs its own subfolder with video files inside it (standalone films go in a Movies folder). See Name folders and files for an example layout.
  • External drive disconnected: A folder marked Unavailable means Anibeam can't reach that drive right now. Plug in or mount the drive, then click Rescan next to the folder.

A show isn't recognized or has the wrong poster

Anibeam identifies each show from its folder name. Extra release tags, typos, or alternative titles can occasionally cause a miss or pick the wrong season.

Open the show, click Fixes > Find a match (or Match), and search by title or paste its AniList, MyAnimeList, TVmaze, or IMDb link. See Fix a show that wasn't recognized for the full steps.

Episodes are missing, doubled, or in the wrong order

If file names don't have a clear episode number, Anibeam can pair them to the wrong episode or group specials with regular episodes.

  • Open the show, click Fixes > Files, and assign the right episode number or extra type under Should be. See Fix misnumbered episodes or extras.
  • If a show displays an Extra files warning, you have more video files in that folder than the expected episode count (usually duplicates, misnamed files, or unlabeled specials).

Subtitles, audio, or TV casting problems

Subtitles or audio are slightly out of sync
While watching, tap z / Z to shift subtitles by 0.1 seconds or a / A for audio (or click the clock icon in the player bar).
My custom subtitle font or color isn't applying
Most anime files use styled .ass subtitles that bring their own formatting. In SettingsPlayback under Styled subtitles, switch from Size only to Override if you want Anibeam to replace the built-in styling with yours.
My TV or Chromecast doesn't show up, or refuses to play a file
Confirm your computer/phone and TV are on the same local Wi-Fi network (not a guest network or separate VLAN). Note that Chromecasts and most smart TVs cannot decode older 10-bit H.264 (Hi10P) anime encodes. On sideloaded iPhones, iOS restricts local network multicast discovery so casting from iPhone cannot find TVs automatically.

A search on Downloads finds nothing

  • "No sources to search yet": You haven't added a source list yet. Paste a source list link right below that message and click Add. See How to add a source list.
  • "All sources are turned off": Click any source chip under Sources on the Downloads page to turn it back on.
  • A source needs a key or login: Open SettingsDownloads and click Add its value next to any source asking for credentials.
  • Zero results for a specific anime: Release sites often spell titles differently than English databases. Try searching fewer words, or try the Japanese title in Roman letters (romaji), such as Ashita no Tegami instead of Letters for Tomorrow.

Torrent client won't connect

  • If you use your own qBittorrent: Make sure qBittorrent is open and its Web UI is enabled (ToolsOptionsWeb UI). Then open SettingsDownloads in Anibeam, click Test, and click Details to read the exact error.
  • Wrong address or password: Fix the Address, Username, or Password fields and click Save and test.
  • Want Anibeam to handle it instead? Change Which client to Built-in (or Auto) and click Save.

Downloads could not start

By default, modern Anibeam searches sources using its own built-in engine (Anibeam itself under SettingsDownloads > Searches run in).

If your setup still uses the optional external search helper and it stops responding, click Start again on the Downloads page to restart it. If Settings points to a helper you configured manually that isn't running, click Use Anibeam's own (or switch Searches run in to Anibeam itself) to switch back.

A download finished, but it isn't in my library

This almost always means your torrent client saved the files into a folder that Anibeam isn't watching. Check Where downloaded episodes are saved, then add that download folder under SettingsLibrary. Once added, your episodes appear as soon as the scan runs.

AniList or MyAnimeList sign-in didn't finish

  • Make sure you clicked Approve in the browser tab Anibeam opened. If you closed that tab too early, click Open the sign-in page again inside Anibeam.
  • If Anibeam says the local sign-in port is busy, wait a few seconds and try again.
Built from source with your own Client ID?
  • The Redirect URL saved on AniList or MyAnimeList must match Anibeam's address character for character. Click Copy the address in Anibeam and paste it over the old one.
  • Make sure the Client ID comes from that exact app. For MyAnimeList, choose App Type: other (if you chose web, MyAnimeList also requires the Client Secret).

A Watch together room won't open

"No room has that code"
Double-check the 6-character code with whoever sent it. Rooms close automatically once everyone leaves.
"That room is full"
Each Watch together room holds up to 10 people.
"That room uses a newer Watch together version"
Update Anibeam under SettingsAbout so everyone is on a compatible release.
"Could not reach the room server"
Check your internet connection, and verify that Room server under SettingsPlayback > Advanced was not changed by mistake.

Phone app can't reach my computer

  • Make sure the Tailscale app is connected on both your computer and your phone, signed into the same tailnet.
  • Confirm Share over Tailscale is turned on in SettingsAccounts on your computer, and that your computer's Anibeam (or anibeam serve / anibeam-host) is running.
  • If a short name like my-computer:8790 doesn't connect, try the full MagicDNS name (my-computer.example.ts.net:8790) or your computer's 100.x.y.z:8790 Tailscale IP address shown in Settings.
  • Check Devices on your tailnet in SettingsAccounts to make sure your phone hasn't been toggled off.

Back up, restore, or find your Anibeam files

Your library database, watch history, matches, and settings all live locally on your computer. You can open any folder directly or export a single backup file under SettingsAbout:

  • Back up the library: Click Back up to save everything to one .json file you can restore on another computer (turn on Include sign-ins only if you want account credentials included in that file).
  • Restore from a backup: Click Restore and choose your saved backup file.
  • Find folders fast: Scroll to Where Anibeam keeps its files in SettingsAbout and click Open next to any row.

Report a problem

Ran into a bug or a show Anibeam keeps misreading? Reporting it takes less than a minute:

  1. Open SettingsAbout and click Report a problem under Help.
  2. Your browser opens a bug report form on GitHub with your Anibeam version already filled in. Describe what you did, what happened, and attach a screenshot or copied line from Activity if you can.

For episodes that Anibeam parsed incorrectly, you can also click File an issue on GitHub inside Fixes > Files. It pre-fills the show title and file names for you to review before submitting (remember that GitHub issues are public).
