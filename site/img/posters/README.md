# Website posters

Every poster here is an invented show. A poster with no entry in `credits.json` is AI-made, and
the site marks it "AI". A hand-drawn poster replaces the file of the same name and gets an entry,
which swaps the mark for the artist's name:

```json
{ "artists": { "shell-city": { "by": "Your name", "url": "https://example.com" } } }
```

Posters are original art only, never fan art of a real series: portrait 2:3, at least 640 x 960,
no text, licensed CC BY 4.0. See issue #1543.
